# Архитектура Multi-Seat Toolkit
Архитектура Multi-Seat Toolkit состоит из внешних и внутренних программных компонентов. Такая структура обеспечивает масштабирование и упрощает подключение дополнительного оборудования. 

Для того, чтобы вывести список компонентов, воспользуйтесь командой `--list-components`.

## Внешние компоненты

Внешние компоненты устанавливаются на хост-компьютер при развертывании. Они предназначены для настройки интерфейса системы.

- **Awesome** — оконный менеджер для управления окнами в тайловой раскладке.
- **Unclutter** — автоматическое сокрытие курсора мыши при неактивности.
- **Xephyr** — вложенный X Window System сервер, который работает внутри окна основного X-сервера..
- **LightDM** - графическое окружение входа в систему для авторизации
пользователей, запуска и поддержания графических сессий.
- **VirgualGL** - ускорение 3D-графики на рабочих местах.

## Внутренние компоненты

Внутренние компоненты отвечают за фоновые процессы и обеспечивают корректную работу MST.

### mst
Компонент mst является утилитой подготовки конфигурационного файла для корректной работы mstd.

**Функции mst**:

- формирование конфигурации компонента mstd;
- подготовка данных для системной инициализации.

### mstd
Компонент mstd управляет фоновыми процессами Linux в работе Multi-Seat Toolkit.

**Функции mstd**:

- управление работой внешних компонентов на основе конфигурации, описанной в mst;
- запуск пользовательских рабочих мест;
- подключение USB-разъёмов для назначенных рабочих мест.

При отключении mstd система перестает работать.
