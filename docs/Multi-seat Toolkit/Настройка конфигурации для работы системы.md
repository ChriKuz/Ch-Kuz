# Настройка конфигурации для работы системы
После развёртывания системы необходимо выполнить настройку конфигурации.

Настройка конфигурации включает следующие этапы:

1. Запуск компонента mst
2. Настройка USB-разъёмов
3. Выбор и настройка рабочих мест

## Запуск компонента mst
Чтобы запустить компонент mst:

В интерфейсе терминала выполните команду `mst` от имени суперпользователя (root).

После запуска компонента mst откроется окно выбора рабочих мест.

## Настройка USB-разъёмов
Для работы MST все устройства ввода-вывода должны быть подключены через USB-разъёмы.  Каждому рабочему месту необходимо назначить индивидуальный USB-разъём. После настройки устройства, подключенные к назначенному разъёму, будут автоматически привязаны к соответствующему рабочему месту.

Чтобы настроить USB-разъёмы, выполните следующие действия:

1. Запустите Multi-seat Toolkit с учётной записью администратора.
2. В открывшемся окне нажмите кнопку **Начать установку**.
3. Выберите **Настройка USB-разъёмов**.
4. В открывшемся окне выберите USB-разъём и нажмите **Далее**.
5. Выберите рабочее место, к которому необходимо привязать данный USB-разъём. 
5. Нажмите **Завершить**, чтобы перейти к настройке следующего USB-разъёма.
6. После назначения USB-разъёмов всем рабочим местам, нажмите **Сохранить**.

Чтобы изменить настройки назначенного USB-разъёма, выполните команду:
```
mst-umount
```

## Выбор и настройка рабочих мест
Перед настройкой рабочих мест убедитесь, что к хост-компьютеру подключены все дополнительные мониторы.

1. Запустите Multi-seat Toolkit с учётной записью администратора.
2. В открывшемся окне нажмите кнопку **Начать установку**.
3. Выберите **Выбор и настройка рабочих мест**.
3. В поле **Выберите мониторы** выберите мониторы, для которых необходимо настроить рабочие места. Каждому монитору соответствует отдельное рабочее место.
4. В открывшемся окне выберите рабочее место для настройки. Название рабочего места соответствует названию монитора.
5. Подключите USB-приёмник мыши, которая будет использоваться на данном рабочем месте, к USB-разъёму, назначенному данному рабочему месту.
6. С помощью этой мыши нажмите **Далее**.

Калибровка мыши завершена.

8. В открывшемся окне выберите **Перейти к настройке клавиатуры**.
9. Подключите USB-приёмник клавиатуры, которая будет использоваться на данном рабочем месте к USB-разъёму, назначенному этому рабочему месту.
10. На этой клавиатуре нажмите клавишу **Enter**.

Калибровка клавиатуры завершена.

11. В открывшемся окне нажмите **Вернуться к выбору рабочего места**, чтобы перейти к настройке других рабочих мест.
11. После завершения настройки всех рабочих мест нажмите **Сохранить**.

Настройка рабочих мест завершена. 

Параметры рабочих мест хранятся в системном файле:

```
/etc/mst-seats
```

# Перезапуск и выключение системы
Перезапуск MST может потребоваться после изменения настроек рабочих мест или USB-разъёмов.

Если многопользовательская конфигурация больше не требуется, MST можно выключить. При этом настройки системы сохранятся. 
## Перезапуск системы

Для перезапуска MST необходимо перезапустить компонент mstd с помощью команды:

```
sudo systemctl restart mstd
```
## Выключение системы
Для выключения MST выполните следующие команды:

1. Остановите компонент mstd:
```
sudo systemctl stop mstd
```
2. Отключите автоматический запуск компонента mstd после перезагрузки компьютера:
```
sudo systemctl disable mstd
```
3. Переключите хост-компьютер в стандартный графический режим:
```
sudo systemctl set-default graphical
```
