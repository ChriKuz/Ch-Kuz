# Программные и аппаратные требования
Для функционирования Multi-seat Toolkit хост-компьютер должен соответствовать программным и аппаратным требованиям, приведённым в данном разделе.

## Требования к программному обеспечению
Multi-seat Toolkit поддерживается на следующих операционных системах:

* Ubuntu 22.04 LTS;
* ALT Linux 9;
* ALT Linux 10.
