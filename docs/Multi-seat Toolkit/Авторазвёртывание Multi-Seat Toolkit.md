# Авторазвёртывание Multi-Seat Toolkit
Для авторазвёртывания Multi-Seat Toolkit необходимо использовать сценарий install.sh от имени суперпользователя (root). Для ALT Linux и Ubuntu GNU/Linux предусмотрены разные параметры запуска сценария.

## Авторазвёртывание Multi-Seat Toolkit в ALT Linux

Для запуска авторазвёртывания Multi-Seat Toolkit в ALT Linux откройте терминал и выполните следующие действия:

1. Клонируйте репозиторий Multi-Seat Toolkit:

```bash
git clone https://gitlab.com/gkaz/mst.git
```

2. Перейдите в каталог репозитория:

```bash
cd mst
```

3. Запустите сценарий автоматического развёртывания от имени суперпользователя:


```bash
sudo ./install.sh alt
```

4. Введите `y` и нажмите **Enter** для подтверждения установки.

После успешного завершения сценария автоматическое развёртывание Multi-Seat Toolkit считается выполненным.
